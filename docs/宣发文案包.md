起因是自己看论文时，静态公式和图完全建立不起直觉。

技术上两条路：

   不重写整个文件，然后重新渲染
2. 画布内直接抓：不用找滑块，直接拖画布里的物体改参数

纯静态产物，下载下来离线能用。

仓库：https://github.com/mqu21539-cyber/SciCanvas
展厅（不用装环境）：https://mqu21539-cyber.github.io/SciCanvas/

欢迎拍砖，尤其是物理正确性——模板里的公式我都验过，但自由生成那条路还要抽检。

## Show HN

**Title**：
```
Show HN: SciCanvas – Turn textbook concepts and papers into interactive 2D labs
```

**Body**：

```
I got tired of explaining physics with static LaTeX, so I built a tool that turns a
paragraph or an arXiv link into a playable single-file HTML lab.

How it works: a router first checks 10 parameterized templates (1.5s, physics is
guaranteed correct because the code is hand-written). If nothing matches, a
planner+coder pair writes ~50 lines of JS that runs inside a fixed holographic shell
(4 SVG layers, oscilloscope, filters, ghost trails).

Two things I'm happy with:

- Self-healing: if the generated lab throws at runtime, the error is posted back to
  the backend, which rewrites only the offending JS block (never the whole file),
  then re-renders. Whole-file rewrites kept destroying the shell.
- Direct manipulation: you can drag the object in the canvas instead of hunting for
  the slider. It's opt-in per template via a one-line binding.

Output is a single HTML file with zero external dependencies - works offline.
MIT licensed.

Live gallery (no backend needed): https://mqu21539-cyber.github.io/SciCanvas/
Repo: https://github.com/mqu21539-cyber/SciCanvas

Happy to answer questions about the generation pipeline or the physics.
```
