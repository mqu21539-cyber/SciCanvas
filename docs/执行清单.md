## 已知未做（按性价比排序）

| 项 | 为什么没做 | 要做的话 |
| :--- | :--- | :--- |
| **GitHub 发布** | 建仓库 / Topics / Pages / Social preview / 宣发只能在网页操作 | 照着第 6 节的文案点 |
| arXiv PDF 直读 | 需要 PDF 抽取 + 多图拆解，属独立功能 | 先接 `pypdf` 抽正文，再复用现有 Planner |
| 浏览器首帧仍要 ~1.2 s | 服务端 2 ms 就发出去了，只有 Chrome 收得晚；CORS / 代理 / 首帧大小 / keep-alive 都排除过 | 疑为本机安全软件缓冲 chunked 响应，代码侧无解 |
| 残影是静态快照 | 双轨同步演化要给每个实验写两套状态机 | 改 10 个模板，约 2 天 |
| 画布抓握只接了抛体模板 | 其余 9 个模板没声明 `HOLO.bindDrag` | 每个模板加一行，逐个定「拖什么」 |
| 宝典的 3D 卡片 / 光标放大镜 | 视觉增益小，且与 2.5D 舞台透视打架 | 建议不做 |
| Three.js / 3D | 与"单文件 HTML"契约冲突，token 成本翻倍 | 另开 3D 模板族，不走自由生成 |
| BYOK 在线生成 | 受第三方 API 的 CORS 限制，不可靠 | 自建同源代理（Cloudflare Worker ≈20 行） |
| 中英双语 README 全量翻译 | 当前是中文主体 + 英文长文在 `docs/README.en.md` | 拆两份独立维护 |
